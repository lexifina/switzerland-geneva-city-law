# Art. 9 Restrictions de prêt
1 Certains documents ne peuvent pas être empruntés, mais ils peuvent être consultés en salle de lecture ou à la médiathèque.
2 Ce sont notamment :
a) les documents portant la mention «consultation sur place» ou «prêt exclu» ;
b) les documents de référence et les consultatifs déposés dans la salle de lecture ou la médiathèque, les bureaux et les bibliothèques des MAH ;
c) les documents antérieurs à 1946 ;
d) les catalogues de ventes aux enchères ;
e) les archives ;
f) les manuscrits, les estampes, les cartes, les affiches, les grands formats (au-dessus de 35 centimètres) ;
g) les fonds précieux ;
h) d'une manière générale, tous les documents précieux et/ou fragiles.
3 La bibliothèque est autorisée à restreindre le prêt, voire à exclure du prêt, des documents pour des raisons de disponibilité, de conservation, de protection des droits selon la loi fédérale sur les droits d'auteur et les droits voisins du 9 octobre 1992 (ci-après : LDA) ainsi que pour d'autres raisons importantes.
