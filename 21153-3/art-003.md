# Art. 3 Employeurs
Les employeurs affiliés sont : a. la Ville de Genève ; b. les Communes affiliées ; c. l’Association des Communes Genevoises (ci-après : l’ACG) ; d. le Centre Sportif de Sous-Moulin (ci-après : CSSM) ; e. le Groupement Intercommunal de la Protection Civile OPC Salève (ci-après : l’OPC Salève) ; f. le Groupement Intercommunal de la Protection Civile Seymaz (ci-après : l’OPC Seymaz) ; g. la CAP ; h. les autres employeurs affiliés conventionnellement.
