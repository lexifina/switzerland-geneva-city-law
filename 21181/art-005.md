# Art. 5 Evaluation des demandes de financement
Le projet faisant l’objet d’une demande de financement dans le cadre de G’innove est apprécié notamment sous l’angle de 9 critères :
1. innovation ;
2. bénéfice sociétal attendu ;
3. ancrage local ;
4. complémentarité avec les politiques municipales existantes ;
5. amélioration des pratiques administratives ;
6. pluridisciplinarité ;
7. qualité de la gestion ;
8. financement ;
9. viabilité et perspectives.
